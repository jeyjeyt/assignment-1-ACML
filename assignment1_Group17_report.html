Software description and how to use it¶

What this notebook does¶

This notebook implements a small neural network, using only NumPy for the math (no Keras, PyTorch or other deep learning libraries).

The network has three layers:

  • 8 input nodes
  • 3 hidden nodes + bias
  • 8 output nodes + bias

It is trained on the 8 one-hot examples (seven 0s and one 1), and the target output is the same as the input. Because the hidden layer has only 3 nodes, the network must learn a compressed representation of the 8 inputs.

Requirements¶

  • Python 3
  • NumPy
  • Matplotlib

How to run¶

Open the notebook and choose Kernel → Restart & Run All. The two experiment cells train 90 and 70 networks, so each takes about 1–2 minutes.

Structure of the notebook¶

  1. Setup: imports, sigmoid function, training data
  2. 8-3-8 network: one forward pass, one backpropagation step, to show the cost decreasing, then the full training loop
  3. Training function: the same steps packed into train_network(), used for all experiments
  4. Experiments: learning rate, starting weight size, cost plot
  5. Interpretation: hidden activations and learned weights

Implementation choices¶

  • Activation function: sigmoid, g(z) = 1 / (1 + e^(−z))
  • Cost function: least squares, J = 1/(2m) · Σ ‖h(x) − y‖²
  • Biases are stored as separate vectors (b1, b2) instead of as an extra column inside the weight matrix Θ.
  • Full-batch gradient descent: in each epoch, all 8 examples are used and the weights are updated once with the average gradient.
  • No weight decay (λ = 0).
  • Weights start as small random numbers from a normal distribution; biases start at 0.
  • Convergence: we say the network has converged at the first epoch where (1) for every example, the largest output is in the correct position, and (2) the cost J is below tol (default 0.01).

How to use the training function¶

converged_at, history, A1 = train_network(lr=2.0, seed=0, init_scale=0.5,
                                          max_epochs=20000, tol=0.01)
Parameter Meaning

It returns the epoch where the network converged (None if it never did), the cost at every epoch, and the final hidden activations.

Forward propagation¶

Activation function: Every hidden and output neuron uses the sigmoid, g(z) = 1 / (1 + e^(−z)). It squashes any number into the range 0 to 1, so each neuron's output can be read as probability.
Its derivative is g′(z) = g(z)(1 − g(z)), which we use in backpropagation.

Training data: X = np.eye(8) gives the 8 one-hot examples (one row per example). The target Y is the same as the input, because the network must reproduce it.

Weight initialisation: The weights W1 (8 × 3) and W2 (3 × 8) start as small random numbers from a normal distribution (standard deviation 0.5), and the biases b1, b2 start at 0.
The weights must be random and not all equal, otherwise all hidden neurons would learn exactly the same thing.
The seed makes the random start reproducible.

Forward pass: The input goes through the network layer by layer:

  1. Hidden layer: A1 = g(X·W1 + b1). Each hidden neuron takes a weighted sum of the inputs, adds its bias, and applies the sigmoid.
  2. Output layer: A2 = g(A1·W2 + b2). The same, using the hidden outputs as input.

Because we use matrices, one line computes all neurons of a layer for all 8 examples at once.

Cost: We measure how wrong the network is with J = 1/(2m) · Σ ‖A2 − Y‖², where m = 8 is the number of examples. Before training, all outputs are close to 0.5 and the cost is about 1.165: the network has not learned anything yet.

One backpropagation step¶

We first show a single backpropagation step on its own, before the full training loop. We built the network step by step, following the same order as the lecture: first the forward pass, then the errors of the output and hidden neurons, then the weight update. Splitting the problem into these smaller tasks made it easier to understand and check each part separately. Showing one step also lets us see directly that the cost decreases after a single update. The backpropagation step finds out how much each weight contributed to the error, so that we can change each weight in the direction that reduces the cost.

Error of the output neurons: d_out = (A2 − Y) · A2(1 − A2) This is (how wrong the output is) × (the derivative of the sigmoid). The derivative tells how much the neuron can still change: it is largest at 0.5 and almost zero when the neuron is close to 0 or 1.

Error of the hidden neurons: d_hid = (d_out · W2ᵀ) · A1(1 − A1) The hidden neurons have no target, so we cannot compare them with a correct answer. Instead, the output errors are sent backwards through the weights W2: a hidden neuron with a strong connection to a wrong output gets a big share of the blame. This is again multiplied by the sigmoid derivative.

Gradients and update: The gradient of a weight is (error of the neuron it goes into) × (value of the neuron it comes from), averaged over the m examples:

  • W2 gradient: A1ᵀ · d_out / m
  • W1 gradient: Xᵀ · d_hid / m

The Bias: The bias of a neuron works like a weight on an input that is always 1, so its gradient is just the average error of that neuron: d_out.mean() and d_hid.mean().

Every parameter is then updated with gradient descent: new value = old value − learning rate × gradient. All gradients are computed first and only then applied, in order to guarantee a simultaneous update.

After this single step, the cost drops from 1.17 to 0.89.

lr = 2.0         # learning rate
# delta of the output 
d_out = (A2 - Y) * A2 * (1 - A2)

# delta of the hidden 
d_hid = (d_out @ W2.T) * A1 * (1 - A1)

# update every weight
W2 -= lr * (A1.T @ d_out) / m
b2 -= lr * d_out.mean(axis=0)
W1 -= lr * (X.T @ d_hid) / m
b1 -= lr * d_hid.mean(axis=0)

# forward propagation with the new weights and check the cost
A1 = sigmoid(X @ W1 + b1)
A2 = sigmoid(A1 @ W2 + b2)
J = 0.5 * np.sum((A2 - Y) ** 2) / m

Training loop¶

Training simply repeats the forward pass and the backpropagation step many times. One epoch = all 8 examples are passed forward once, followed by one weight update.
We train for 20,000 epochs with learning rate 2 and print the cost at a few moments: it keeps decreasing, from 0.89 to 0.0012.

    # forward
    A1 = sigmoid(X @ W1 + b1)

    W2 -= lr * (A1.T @ d_out) / m
    b2 -= lr * d_out.mean(axis=0)
    W1 -= lr * (X.T @ d_hid) / m
    b1 -= lr * d_hid.mean(axis=0)

Training function¶

train_network() contains exactly the same steps as above (initialisation, forward pass, backpropagation, update), packed into one function so that we can run many experiments with different parameters. It also records the cost at every epoch and the first epoch where the network converged. In the cell below, it reproduces the result of the step-by-step version.

In [37]:
def train_network(lr=2.0, seed=0, init_scale=0.5, max_epochs=20000, tol=0.01):
    # seed fixes the random starting weights, so results are reproducible
    # init_scale is the standard deviation of the random starting weights
    # max_epochs is the maximum number of training epochs
    rng = np.random.default_rng(seed)
    W1 = rng.normal(0, init_scale, (8, 3)); b1 = np.zeros(3)
    W2 = rng.normal(0, init_scale, (3, 8)); b2 = np.zeros(8)
    m = X.shape[0]
    history, converged_at = [], None

    for epoch in range(1, max_epochs + 1):
        # forward
        A1 = sigmoid(X @ W1 + b1)
        A2 = sigmoid(A1 @ W2 + b2)
        J = 0.5 * np.sum((A2 - Y) ** 2) / m
        history.append(J)
        # converged = first epoch where all guesses are correct and cost is below tolerance
        if converged_at is None and np.all(A2.argmax(1) == Y.argmax(1)) and J < tol:
            converged_at = epoch
        # backward
        d_out = (A2 - Y) * A2 * (1 - A2)
        d_hid = (d_out @ W2.T) * A1 * (1 - A1)
        W2 -= lr * (A1.T @ d_out) / m;  b2 -= lr * d_out.mean(axis=0)
        W1 -= lr * (X.T @ d_hid) / m;   b1 -= lr * d_hid.mean(axis=0)

    A1 = sigmoid(X @ W1 + b1)   # final hidden values
    return converged_at, history, A1

To check whether the network learns reliably, we ran two experiments. For every setting we trained 10 networks with different starting weights (different random seeds), each for at most 20,000 epochs. One epoch = all 8 examples shown once, followed by one weight update.

  • 0.01–2: always converges, fastest around 0.5.

  • 5: only half of the networks converged, and slowly. With large weights the sigmoid neurons start close to 0 or 1, where their slope a(1 − a) is almost zero. The gradients are then tiny, so the neurons are almost frozen and learn very slowly.

  • All weights 0 :if every weight starts at the same value, all three hidden units compute exactly the same thing.
    They then receive exactly the same error signal during backpropagation, so they get the same updates and stay identical.
    In theory, the network then behaves as if it had only one hidden unit, and one unit is not enough to tell 8 inputs apart.
    This is called the symmetry problem, and it is the reason why weights are normally initialised randomly, symmetry breaking.

    In our run, the network still converged, but it needed 14580 epochs, about 10 times more than with small random weights, 1338 epochs for size 0.5. The hidden activations, printed in the cell below, explain why.

Hidden units 1 and 2 have exactly the same value for every input, so they never separated.
Hidden unit 3, however,became different. Since nothing in the code is random when all weights are 0, this difference most likely comes from tiny rounding errors in the computer's calculations, which broke the symmetry by accident.
Backpropagation then slowly made this tiny difference bigger. As a result, the network had effectively only two different hidden units instead of three. It still managed to separate the 8 inputs, but only by using in-between values, such as 0.26 and 0.72 instead of a clean on/off code, which is harder and therefore much slower to learn.
The seed has no effect here: with a starting weight size of 0, every weight is exactly 0, no matter the seed. All 10 runs were therefore the same network, which is why all 10 gave the same result. To sum up the first two columns, hidden units 1 and 2, are identical in every row, while the third column is different.

Conclusion: the weights must start small and random, to break the symmetry between hidden units without saturating the sigmoid.

The hidden layer learned a binary-like code¶

Most hidden activations are close to 0 or 1, so each hidden unit behaves almost like an on/off switch. With 3 switches there are exactly 2 × 2 × 2 = 8 possible patterns, and the network uses every pattern exactly once.

Why every input needs a different code: the output layer only receives the 3 hidden values, it never sees the original input. If two inputs produced the same hidden pattern, the output layer would receive exactly the same information for both and could not know which output to switch on. To reproduce all 8 inputs correctly, every input must therefore get its own pattern. With only 3 hidden units, this forces the network to use all 8 combinations.

The code is not ordinary binary counting: input 0 gets 1 0 0, not 0 0 0. Which input gets which pattern is arbitrary, and depends on the random starting weights.

The code is binary-like, but not perfectly binary: some values are clearly not 0 or 1. For example, input 4 has a middle value of 0.59, and input 5 has 0.20 and 0.15. The network does not need perfect 0s and 1s: the codes only need to be different enough for the output layer to tell them apart. Our all-zero experiment showed the extreme case of this, where the network used in-between values such as 0.26 and 0.72 instead of an on/off code.

The weights: W1 is a code book, W2 is a decoder¶

W1 (input → hidden): Each input contains a single 1 and seven 0s, so input i only "activates" row i of W1: all other rows are multiplied by 0. Row i of W1 therefore directly determines the hidden code of input i. A positive weight switches the hidden unit on, a negative weight switches it off:

Input Row of W1 Signs Hidden code
0 5.0, −1.4, −3.9 + − − 1 0 0
1 2.5, −5.0, 3.3 + − + 1 0 1
3 −4.7, −1.5, 4.4 − − + 0 0 1
7 5.0, 3.8, 5.1 + + + 1 1 1

So W1 stores one 3-bit code per input. The size of the weight also matters. Input 4 has a middle weight of only 0.1, which is why its middle hidden value (0.59) is the least clear of all.

W2 (hidden → output): Each column of W2 belongs to one output unit. The signs of each column match the code of the input that output should reproduce:

Output Column of W2 Signs Matches code of input
0 9.9, −6.9, −8.9 + − − 0 (1 0 0)
1 6.1, −9.6, 6.2 + − + 1 (1 0 1)
4 −12.0, 4.8, −11.4 − + − 4 (0 1 0)
7 6.2, 6.3, 5.9 + + + 7 (1 1 1)

Each output unit has learned a template of its own code: positive weights where its code has a 1, negative weights where its code has a 0. It only gets a large positive input when the hidden pattern matches its template, so it lights up for its own input and stays off for all others.

Together, the network works as an encoder–decoder: W1 compresses the 8 inputs into a 3-dimensional code, and W2 decodes that code back into the original input. This is an example of what the lecture calls a latent representation: a hidden, compressed description of the data that the network discovers by itself.

Conclusion¶

We implemented an 8-3-8 neural network with backpropagation from scratch, using only NumPy. The network learned to reproduce all 8 one-hot inputs.

Learning is reliable: for every learning rate between 0.5 and 50, all 10 random starts converged. A learning rate around 20 was fastest (376 epochs on average), while values that were too small (0.1) or too large (100) did not converge. The starting weights must be small and random: too large weights saturate the sigmoid and slow learning down, and all-zero weights create a symmetry problem between the hidden units.

Looking inside the trained network, the 3 hidden units learned a binary-like code, using all 8 possible on/off patterns. W1 acts as a code book that assigns a code to each input, and W2 acts as a decoder that turns the code back into the original input. The network discovered this compressed representation entirely by itself.
